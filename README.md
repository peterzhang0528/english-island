# 英语方块岛

Minecraft 风格的 3D 英语互动小游戏，依据 https://yingyufan.com/ 首页小游戏复刻与改编。保留开门、收集原木、制作木板木棍、寻找石头、合成石斧、砍树通关的交互流程；独立提供声音开关、玩法说明、键盘操作、词汇点读、重玩和纪念卡片。

## 运行

需要 Node.js 22.13 或更新版本。

```sh
npm install
npm run dev
```

访问终端显示的本地地址。正式构建使用 `npm run build`。

只运行游戏本体时，不需要安装依赖：

```sh
python3 -m http.server 8080 --directory public
```

然后打开 http://localhost:8080/game/ 。不要直接双击 HTML，浏览器 ES 模块需要 HTTP 服务。

## 第二关：给僵尸做蛋糕

顶部「选择关卡」可以切换两关，第一关完成后也可以直接进入第二关。网址加上 `?level=2` 可直接打开第二关。

第二关流程：认识饥饿的新朋友 → 找小鸡拿鸡蛋 → 向奶牛收集牛奶 → 收割三束麦子 → 在厨房制作蛋糕 → 把蛋糕分享给僵尸。配有 27 段新增本地英文配音、食材进度、友谊对话和专属通关卡片。使用简单的小岛配方，不等同于 Minecraft 的完整合成规则。

第二关为原创场景与玩法实现，复用第一关的渲染库和视觉基础。通过 `public/game/day2.html` 也可独立运行。

## 玩法

点击「推开这扇门」，听中英文提示，点击金色光圈指引的目标。也可以使用右侧动作按钮或空格键。拖动场景转动视角；点击羊、花、水等物体发现额外单词。通关后可以点读单词、生成图片卡片或重新开始。

## 结构

- `app/`：独立游戏入口、任务进度与控制栏。
- `components/IslandGame.tsx`：隔离的游戏载入与状态同步。
- `public/game/`：可独立部署的游戏本体，含本地几何、贴图生成、音效及 59 段语音。
- `public/game/js/vendor/`：Three.js r186.1（保留 MIT 许可声明）。

核心场景与玩法改编自所提供参考站的公开前端资源；本项目没有参考站的预约业务。第三方名称、角色及原素材权利归其原权利人。
