# 十天，一起把小岛变成家

这段故事的主角是玩家、英语伙伴 JJ，以及第二关认识的友善朋友。英语和动作一起出现：把一个词变成一次帮助，把一次帮助变成下一段旅途。

## 每一关都有自己的小故事

### 04 · 把花送过小桥

第三天，我们和朋友种出了花园。小蜜蜂带来消息：河对岸的集市需要鲜花，可小桥少了几块木板。

任务：寻找木板 → 系好绳子 → 敲牢木板 → 走过小桥 → 推走花车。

纪念物：**鲜花小推车**。把第三关种出的花，送到第五关的集市。

### 05 · 集市里的小委托

我们推着花车过了新修的小桥。集市上的朋友正等着鲜花，还想请我们帮一个忙。

任务：送出鲜花 → 拿起篮子 → 装好苹果 → 带上面包 → 打开地图。

纪念物：**寻羊地图**。地图通向第六关的牧场，也画着远处的海湾。

### 06 · 跟着脚印找小羊

集市朋友画的地图带我们来到牧场。草地上有一串小脚印，面包篮也陪着我们一起走。

任务：寻找脚印 → 打开栅栏 → 找到小羊 → 喂饱小羊 → 收下羊毛。

纪念物：**一篮软羊毛**。第七关会把这份谢礼变成小船的白帆。

### 07 · 白帆带我们出发

小羊回家了。牧场的朋友把羊毛织成白帆，我们带着白帆和旅途食物来到码头。

任务：搬来木料 → 升起白帆 → 登上小船 → 迎接微风 → 驶向小岛。

纪念物：**白帆小船**。小船会停靠在第八关的灯塔码头。

### 08 · 让灯塔亮起来

我们的白帆小船靠岸了。灯塔守护着来往的小船，可今天它的灯还没有亮。

任务：登上台阶 → 找到钥匙 → 打开塔门 → 点亮灯光 → 敲响钟声。

纪念物：**温暖的灯光**。第九关里，这束光会陪朋友们度过雨天。

### 09 · 雨天也要互相照顾

灯塔亮着，我们顺着熟悉的航线回到小岛。一场小雨来了，集市的朋友正在照顾自己的小摊。

任务：看看雨云 → 修好屋顶 → 搬好食物 → 分享雨伞 → 打开来信。

纪念物：**庆典邀请函**。第十关，所有旅途中认识的朋友都会出现。

### 10 · 我们一起建成的小岛

我们有了斧头和桥、蛋糕和花园、白帆和灯塔，也找回了小羊。雨后的今天，朋友们决定办一场属于大家的庆典。

任务：升起彩旗 → 布置餐桌 → 分享蛋糕 → 奏响音乐 → 邀请合影。

纪念物：**十关冒险合影**。记住每一位朋友，也欢迎和大家一起共创下一段故事。

## 共创时保持什么

新故事应接住已有角色或物品，也给下一段故事留出一个自然的理由。保持每次帮助的目的清楚，给玩家看得见的变化：桥补好了、船帆升起来、灯亮了、朋友聚在一起。

旁白以简单英语和对应中文呈现；新增语音沿用 JJ 的参考声线。自由跳关时，前情回顾要能让玩家理解当前任务；不要求先解锁前面的关卡。

AI 功能暂未实现。共创讨论从具体的玩家体验出发，例如一个自然的开口时机、一段能一起编的对白、一个可以由同学设计的任务。先提出例子和判断效果的方法，再讨论实现。
