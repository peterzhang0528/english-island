- 课堂里项目所有者说过，当前这个版本只能给国外同学玩。这句话是现象说明，不是新的部署授权。

因此，国内或校园网打不开官方地址是真实风险。今晚没有从大陆网络复测这个具体主机名，不能把「有时受干扰」写成「所有大陆网络都绝对打不开」，也不能写成「已经从大陆打开过」。

`api.openai.com` 不作为国内直连依赖。静态镜像可以玩十关故事；自由输入生成愿望地图必须走带密钥的服务器，不能靠把网页拷到国内来实现。

## 镜像里有什么

只复制选定提交里的 `public/game/`（当前约 3.6 MB、234 个文件）。保持目录结构，入口是 `index.html`。用 HTTP 打开，不要用 `file://`。

| 路径 | 内容 |
| --- | --- |
| `index.html` | 第一关，通关后进入 `day2.html` |
| `day2.html`、`day3.html` | 第二、三关 |
| `story.html?level=4` … `level=10` | 第四至十关；直接打开时页面自带关卡选择 |
| `wish.html` 与 `wish-examples.json` | 仅 v0.5.0 及之后的提交才有。可玩提前做好的示例地图。没有 `/api/wish` 时，自由输入不会生成新地图 |
| `audio/` | 现有 JJ 配音。服务器需按扩展名提供 `audio/mpeg`，脚本提供 JavaScript，`json` 提供 `application/json` |

静态页面没有网站外壳的 `island-last-level`。从 `index.html` 进入会从第一关开始。这和官方网站「记住最近关卡」不是同一套行为。

选定提交前先对照仓库：`v0.4.0` 标签没有愿望地图文件；`main` 上的 v0.5.1 修了 Worker 生成失败，但官方站在 2026-11-11 当晚核实到的仍是 v0.5.0 客户端。镜像用哪一个提交，由所有者指定。

## 方案 A：放进已经能在课堂打开的网站

如果某个学校网站在大陆课堂里已经能打开，可以把 `public/game/` 的内容放到该站的子目录，例如 `/island/`，入口为 `https://该站域名/island/index.html`。

这和「把现在的 chatgpt.site 链接加到学校网站」不是同一件事。加链接仍然指向可能打不开的官方地址；托管文件才会让页面从那台已经能访问的服务器出来。

步骤：

1. 所有者指定 git 提交（完整 SHA）和子目录路径。
2. 网站所有者同意上传，并确认该站的备案与空间允许这些静态文件。
3. 只上传 `public/game/` 内的文件，保留 `js/`、`audio/`、`assets/` 相对路径。
4. 抽查响应头：`index.html` 为 `text/html`，`js/world.js` 为 JavaScript，`audio/voice.json` 为 JSON，任意一个 `.mp3` 为 `audio/mpeg`。
5. 用大陆手机实际打开第一关，推一次门，再进入第二关，确认画面和 JJ 配音能加载。
6. 把实测地址写回 Issue。不要改 README 或官方链接，除非所有者明确说替换。

本仓库的助手不联系学生，也不代替网站所有者上传。

## 方案 B：大陆对象存储加已备案的自定义域名

2024-01-01 之后新建的腾讯云 COS 存储桶，不能靠默认域名或静态网站默认域名在浏览器里预览页面。需要自定义域名，源站类型选择静态网站。域名用于中国大陆地域时，必须已完成**网站备案**；只做 App 备案不能接入。依据：

- [设置静态网站](https://cloud.tencent.com/document/product/436/32670)
- [绑定自定义域名](https://cloud.tencent.com/document/product/436/102509)
- [托管静态网站](https://cloud.tencent.com/document/product/436/9512)

阿里云 OSS 托管静态网站同样要求中国大陆地域使用已备案的自定义域名。GreatFire 的 2026 年列表把 `aliyuncs.com` 标为未被封锁；学生实际访问的应是自定义域名，上线前仍要用大陆手机打开该域名，不能只看平台默认域名。

步骤（腾讯云 COS；阿里云按对应控制台做同样的几件事）：

1. 使用已实名的云账号。确认费用由谁支付。
2. 在中国大陆地域新建存储桶，权限为公有读、私有写。打开静态网站，索引文档填 `index.html`。
3. 上传选定提交的 `public/game/` 内容到桶的根目录，或上传到子目录并让索引入口指向该目录的 `index.html`。不要把整个 git 仓库、`.dev.vars` 或密钥上传上去。
4. 在「自定义源站域名」添加域名，源站类型选**静态网站源站**。记录控制台给出的 CNAME 目标。
5. 在域名 DNS 控制台添加 CNAME。解析生效后，为该域名绑定 HTTPS 证书。
6. 用大陆手机访问 `https://该域名/`（或约定的子路径）。检查第一关、一次推门、第二关和一段配音。若该提交包含 `wish.html`，再打开示例地图，并确认自由输入给出「暂时没连上」而不是假装已经生成。
7. 把桶名、地域、域名、CNAME、实测时间和结果记到 Issue。官方 chatgpt.site 地址保持不变，直到所有者另有确认。

## 所有者必须逐项确认的内容

未确认前，不创建线上资源，也不公布新地址。

1. 是否允许发布一个国内镜像。允许的话，使用哪一个完整 git SHA。
2. 镜像只包含十关故事，还是同时放上示例愿望地图。自由输入生成不包含在静态镜像里。
3. 用方案 A 还是方案 B。方案 A 要写明已有网站的域名、子目录，以及谁有权上传。
4. 方案 B 要写明：云账号所有者、地域、自定义域名、域名注册商、谁能改 DNS、网站备案号与备案主体、备案接入商是否就是这次使用的云厂商。
5. 新地址是否可以写进 README 或替换官方链接。默认不可以。
6. 是否在公网检查通过后通知「AI小学活动通知群」。默认不通知。

GitHub Pages、Cloudflare Pages 和 `chatgpt.site` 不作为这次的国内入口。不要把绕过防火墙或校园网过滤写成给学生的步骤。
